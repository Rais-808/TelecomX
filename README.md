📊 Análise de Evasão de Clientes (Churn)

Este repositório contém um notebook de análise de churn em uma empresa de telecomunicações.
O objetivo do estudo é identificar fatores que influenciam a evasão de clientes e propor estratégias de retenção baseadas em evidências extraídas dos dados.

📌 Objetivos do Projeto

Explorar e tratar os dados de clientes.

Identificar padrões associados ao churn.

Comparar o comportamento de clientes que permanecem vs. clientes que cancelam.

Fornecer insights estratégicos para reduzir a evasão e aumentar a retenção.

🛠️ Tecnologias Utilizadas

Python 3

Pandas → manipulação e limpeza de dados

Matplotlib / Seaborn → visualizações

NumPy → suporte a cálculos numéricos

🔎 Principais Etapas da Análise

Extração dos dados → conversão de JSON para DataFrame.

Transformação dos dados → limpeza, padronização e criação de variáveis.

Análise Exploratória → estatísticas descritivas e gráficos.

Análise por categorias → impacto de fatores como idade, dependentes, serviços contratados e forma de pagamento.

Análise por variáveis numéricas → meses de contrato, pagamento mensal, pagamento total e contas diárias.

Conclusões finais → fatores de maior influência no churn e sugestões de retenção.

✍️ Desenvolvido para fins de estudo e prática em análise de dados e retenção de clientes.
